# PlayPark Market · 공개 체험 데모

https://playpark-admin.github.io/playpark-market-demo/

파크골프 전문 마켓의 화면과 구매·판매·운영 흐름을 체험할 수 있습니다.
가격·재고·본인확인·결제·배송·정산은 모두 테스트용입니다.
거래가 실제로 성립하거나 금액이 청구되지 않습니다.

입력 데이터는 이 브라우저에만 저장됩니다. 가상 주소·연락처를 사용해주세요.
사이트 상단의 ‘체험 초기화’로 저장된 내용을 삭제할 수 있습니다.
쇼핑 도우미는 조건·화면 기반 안내이며 실제 AI 사진 분석은 연결하지 않았습니다.

이 저장소는 배포용 정적 파일만 보관합니다. 전체 편집용 소스는 계정의 비공개 저장소에서 관리합니다.
사용자 제공 로고·캐릭터·카탈로그의 별도 재사용 권한은 부여하지 않습니다.

main 브랜치를 업데이트하면 GitHub Actions가 GitHub Pages에 배포합니다.
